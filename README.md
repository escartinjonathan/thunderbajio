# Thunder Bajío — Control de clientes

App web (PWA) para registrar y controlar clientes de Thunder TV y Black Eye.

## Archivos
- `index.html` — toda la app
- `sw.js` — funcionamiento sin conexión
- `manifest.json` e `icon-*.png` — instalación como app
- `.nojekyll` — evita que GitHub Pages procese el sitio

## Publicar en GitHub Pages
1. Sube estos archivos a la raíz de un repositorio.
2. En Settings → Pages elige la rama `main` y la carpeta `/ (root)`.
3. Abre la URL que te da GitHub e instala la app desde Chrome.

Los datos se guardan solo en el dispositivo. Descarga respaldos desde Finanzas.
